# Reto - CRUD USUARIOS

## Dev
1. Clona o descarga el repositorio.
2. Abre el proyecto en Visual Studio o cualquier editor compatible con .NET.
3. Ejecuta el script de SQL SERVER
4. En caso de querer cambiar los accesos de la cadena de conexión a la base de datos, cambiar desde el archivo appsettings.Develpment.json
    `server=localhost;Database=DB_USUARIO;User ID=bestrada;Password=123456;TrustServerCertificate=True`
5. Depurar el backend
